# Code of Conduct

## Our Standard

This project expects respectful, professional, and constructive collaboration.

Examples of expected behavior:

- Give technical feedback directly and respectfully.
- Focus discussion on facts, reproducibility, and user impact.
- Assume good intent while still holding a high engineering bar.

Examples of unacceptable behavior:

- Harassment or personal attacks
- Repeated hostile or disruptive behavior
- Publishing private or sensitive information without permission

## Enforcement

Project maintainers may remove comments, close threads, or restrict participation when behavior harms the project or contributors.

## Reporting

Report conduct issues privately to the project maintainer with links, screenshots, or context where possible.
